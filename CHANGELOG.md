# Changelog

## 1.0.2 — 2026-10-13

Publish the prepared plugin package under the confirmed GitHub account and
repository `WiserMap/WiserMap`. Update repository references to the new namespace.
The hosted MCP endpoint and business workflow are unchanged by this package release.

## 1.0.1 — 2026-10-13

Updated the four skills to use the hosted connector's 13 action-specific tools.
Added explicit permission guidance and documented the unverified Claude Code
authentication boundary. The package still contains no private server code.

## 1.0.0 — 2026-10-13

Initial public-distribution package for the existing hosted WiserMap connector.
Includes four skills, remote MCP configuration, marketplace metadata, documentation,
static validation and a behavioral evaluation specification. This version number
belongs to the plugin package, not the independently versioned server. Directory
publication and authenticated reviewer testing are tracked outside the public bundle.
